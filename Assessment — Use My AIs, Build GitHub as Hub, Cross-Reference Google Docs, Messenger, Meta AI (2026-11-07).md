## Cross-reference design — the excellent part
One master index, in GitHub, one line per piece:
- File name + date stamp + repo + Docs link (if any) + Messenger date (if sent) + which AI(s) touched it + tier ([D]/[H]/[H→D]/[GAP]/[PARTIAL]) + status (draft / tested / filed / sent).
- That index is what makes "build everything back from GitHub" possible: Ember does not have to re-open 56 chats, she reads the index, then the file.
- The Shared Research Bundle PDF is the human-readable version of that index, but its links expired Nov 6 — a fresh bundle with fresh links is needed, and the GitHub index does not expire.

## Risks, plainly
- Public GitHub is public. Anything pushed there can be read by anyone. Keep private material out — that rule is already standing, and it is the main risk.
- Convergence is not validation. If all AIs agree, that is a soft signal, not proof. File disagreements, do not smooth them over.
- Two masters will drift. If Docs and GitHub are both edited, they will disagree. Pick GitHub as master, Docs as dump, and say so in every file header.
- Usage: building the hub uses Muse allowance (18% used Nov 7, 82% left, reset Nov 14). The AIs themselves are free / separate meters, but Ember's assimilation here is not free. Cheap first: Markdown files, plain links, no beautiful artifacts until the hub is filled.
