# Research — Other AIs, Least Restrictive Usage Limits (2026-11-07)

**Checked:** November 7, 2026 (all limits below carry this check date unless a different date is stated beside them).
**Ordered by:** Douglas Schoonover, Nov 7, 2026 — find other AIs Ember can use, ranked by least restrictive usage limits, for his research work.
**Method:** Web search + page reads only. No sign-ups, no accounts created, no personal / lab / family material entered anywhere, no purchases, nothing pushed to GitHub. Report filed locally only.

## How to read this file

- **Provider page** = the limit as stated on the provider's own site or docs. **Secondary** = a tracker / review / hands-on test. Where the two disagree, both are shown and the figure is marked **unverified**.
- Limits change often. Every limit below is a dated snapshot (Nov 7, 2026), not a permanent fact. Re-check before building a workflow on any one number.
- **Two lenses matter, and they are not the same:** (a) raw message allowance, and (b) fit for the actual job — open a browser instance, paste an instruction block, get packaged text back to file to GitHub. API-only services can look generous on (a) and be useless on (b), because they need code and an API key, not a tab. The ranking below uses (b) first, with (a) shown beside it.

## Correction to tonight's working notes — Meta AI is no longer "no paid tier"

Earlier tonight Meta AI was recorded as free with no paid tier and no limits. That is now **out of date**. As of **Nov 4, 2026** (Justin McKelvey, reading Meta's own FAQ at ai.meta.com/meta-ai):

- Meta AI is still **free for everyday use** (meta.ai, Meta AI app, WhatsApp, Instagram, Facebook, Messenger).
- Meta's own FAQ now says it **has started testing daily and monthly limits on its more compute-intensive features** (image and video generation/editing, voice). When you hit one, you can buy more usage through **Meta One: Core $7.99/month or Premium $19.99/month**.
- **Meta publishes no number for any of those limits** — not free, not Core, not Premium. Any review quoting a number is guessing.
- **Everyday text chat has no published ceiling.** The limits land on the expensive media features, not on ordinary text.
- Source type: **provider page** (Meta FAQ, read Nov 4, 2026) via secondary write-up. Status: **verified as a provider statement; the numbers themselves are unpublished by design.**
